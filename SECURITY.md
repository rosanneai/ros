# Security

If you believe you've found a security issue in ROS, please report it privately rather than in public, using the contact listed at [rosanne.ai/.well-known/security.txt](https://rosanne.ai/.well-known/security.txt).

Please include the version of ROS (ROS › About ROS), your version of macOS, and the steps that show the issue.

## Supported versions

Security fixes go into the latest release. ROS installs updates by itself, so keeping automatic updates on (Settings › General) keeps you protected.
